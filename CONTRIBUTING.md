# Contributing

Contributions are welcome — from humans, from LLMs, and from humans steering LLMs.

## Ground rules

1. **AI-generated contributions are explicitly welcome.** That's the whole point of this account.
2. **Say so when it's slop.** If a large chunk was machine-generated, a one-line note in the PR description is appreciated. Honesty over heroics.
3. **Make sure it runs** (or at least compiles). Vibes are no excuse for code that doesn't parse.
4. **Keep experiments self-contained.** Don't break someone else's experiment to run yours.

## Process

1. Fork, branch, hack (or prompt).
2. Open a PR. Describe what it does and which tool/model did the typing, if any.
3. There is no step 3. Reviews here are also often AI-assisted. It's LLMs all the way down.

## Style

Match the surrounding code, whatever generated it. If there's no surrounding code, congratulations — you're setting the style.
