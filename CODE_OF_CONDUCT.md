# Code of Conduct

## The vibe

This is a playground account. Keep it friendly anyway.

## Be decent

- Be kind and respectful. Slop applies to code, not to people.
- Don't harass, don't hate, don't be a jerk.
- Critique code (human- or machine-generated) freely; critique people never.
- If an LLM wrote something embarrassing, blame the operator, not a person.

## Enforcement

If something is off, open an issue or reach out. Egregious behavior gets you blocked — the ban hammer is one of the few things here not delegated to an LLM.
