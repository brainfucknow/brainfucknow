# Security Policy

## Reality check

This is an experimental vibe account. **Nothing here should be relied on in production.** Code may have been generated by an LLM that was feeling confident that day.

That said, if you find a genuine security issue:

## Reporting a vulnerability

- **Do not** open a public issue for sensitive reports.
- Use [GitHub's private vulnerability reporting](../../security/advisories/new) on the affected repository, or contact the account owner via their profile.
- Include what you found, where, and how to reproduce it. If an LLM found it, that's fine — just include the repro.

## Response

Best effort. This is a hobby account, but real vulnerabilities get real attention.
