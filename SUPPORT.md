# Support

## The honest answer

This is a vibe/experiment account. There is no SLA. There is barely an SL.

## Where to ask

- **Questions about a repo** → open an issue on that repo.
- **"Why is this code weird?"** → an LLM probably wrote it. Open an issue anyway; curiosity is welcome.
- **Something broken?** → issue with repro steps, please.

## What to expect

- Replies happen when they happen.
- Your question may be answered by an AI assistant. On this account, that's a feature, not a bug.
